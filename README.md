# Java Studies

Repositorio de estudos em Java com exercicios organizados por assunto, cobrindo desde logica de programacao ate temas mais estruturados como orientacao a objetos, interfaces, generics, expressoes lambda e manipulacao de arquivos.

## Visao geral

Este repositorio foi montado como trilha de aprendizado progressiva. Em vez de concentrar tudo em um unico projeto, o conteudo foi separado por modulos para facilitar revisao, pratica e evolucao ao longo do tempo.

## Principais trilhas de estudo

- `sequential – conditional – repetitive`
- `exercises-arrays`
- `exercises-lists`
- `exercises-matrices`
- `oop-exercise`
- `inheritance-polymorphism`
- `interface`
- `generics-set-map`
- `lambda-expression`
- `work-with-files`
- `date-time`
- `string-builder`
- `enumeration-composition`

## O que voce encontra aqui

- exercicios pequenos e objetivos para praticar sintaxe
- problemas de logica resolvidos em Java
- exemplos de POO com classes, heranca e polimorfismo
- estudos de colecoes e estruturas de dados

## Como executar

Como o repositorio e formado por varios exercicios independentes, o fluxo mais simples e:

- abrir a pasta desejada na IDE
- escolher o arquivo `.java` que deseja testar
- executar a classe diretamente

Se preferir, tambem e possivel compilar arquivos individuais pelo terminal com `javac` e executa-los com `java`, de acordo com a estrutura de cada pasta.
